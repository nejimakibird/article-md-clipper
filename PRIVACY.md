# Privacy Policy for Article MD Clipper

Article MD Clipper processes the content of the active web page in the user's browser to extract readable text, links, and Markdown previews.

The extension does not collect, sell, share, or transmit personal data to any external server.

Page content is processed locally in the browser. User settings and temporary data may be stored locally using browser storage.

The extension may use the downloads permission only when the user chooses to save generated Markdown or related output.

If you have questions, please contact us through GitHub Issues.
