# Article MD Clipper

Article MD Clipper is a browser extension that extracts readable article text and selected links from the current web page, then opens a clean Markdown preview for reading, copying, and saving.

## Features

- Extract article text from the active tab
- Collect selected links from the page
- Open a Markdown preview page
- Copy or download generated Markdown
- Process page content locally in the browser

## Privacy

Article MD Clipper does not send page content or personal data to any external server.
